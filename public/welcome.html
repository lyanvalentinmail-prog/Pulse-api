Pulse is a free-access API designed to optimize workflows without the friction of API Keys. What started as a personal toolset has evolved into a public resource driven by the community.

We have migrated our infrastructure to Hono + Bun. This architecture ensures ultra-fast response times and a 100% Type-safe environment for metadata extraction and content downloading.

If you detect third parties commercializing access to this API, report it immediately. This resource is free and open-source for all developers.
